# 用户系统框架

## 1. 目标

在现有 `design` 应用的基础上，补全一套可扩展的用户域：

- 保留现有 Session + Cookie + CSRF 认证（注册/登录/退出/`me` 不变）。
- 新增：个人资料、修改密码、找回密码、RBAC 角色权限、后台用户管理。
- 用 `OneToOne UserProfile` 扩展内置 `User`，**不切换** `AUTH_USER_MODEL`，避免迁移现有数据。

## 2. 分层

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 认证 | `design/auth/*`（既有） | Session 登录注册，前端已接入，暂不动 |
| 用户域 | `users/`（新增） | 资料、改密、重置、RBAC、后台管理 |
| 前端 | `frontend/src/{stores,views,router}` | 账号中心、找回/重置密码页 |
| 后台 | `/admin/users/*` | `UserProfile`、`PasswordResetToken` 管理 |

## 3. 后端目录

```
users/
├── apps.py              # AppConfig
├── models.py            # UserProfile, PasswordResetToken
├── roles.py             # 角色常量与默认权限映射
├── permissions.py       # IsActiveUser / CanManageUsers / IsSelfOrStaff
├── serializers.py       # 资料、改密、重置、后台用户序列化
├── services.py          # 令牌生成/消耗、重置邮件
├── views.py             # MeView 等视图与 AdminUserViewSet
├── urls.py              # /api/users/* 路由
├── admin.py             # 后台注册
└── management/commands/seed_roles.py  # 初始化角色组
```

## 4. 数据模型

- `UserProfile`：`user`(OneToOne)、`display_name`、`phone`、`avatar`、`bio`、`locale`、`timezone`、`email_verified`、时间戳。
- `PasswordResetToken`：`user`、`token_hash`(SHA-256)、`expires_at`、`used_at`；明文令牌只出现在邮件/DEBUG 响应中。

## 5. RBAC

复用 Django `Group`，默认角色：

| 角色 | 名称 | 默认权限 |
| --- | --- | --- |
| `customer` | 普通用户 | 无（按数据归属过滤） |
| `designer` | 设计师 | 查看项目/方案/效果图 |
| `operations` | 运营 | 查看用户、管理订单与线索 |
| `admin` | 管理员 | 用户增删改查 |

- `seed_roles` 命令解析 `users/roles.py` 中的 `app_label.codename` 并绑定。
- 超级用户 `is_superuser=True` 始终放行。
- 对象级权限见 `IsSelfOrStaff`。

## 6. API 端点

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET/PATCH | `/api/users/me/` | 登录 | 读取/更新个人资料 |
| POST | `/api/users/change-password/` | 登录 | 修改密码 |
| POST | `/api/users/password-reset/` | 匿名 | 按邮箱发送重置链接 |
| POST | `/api/users/password-reset/confirm/` | 匿名 | `uid` + `token` 重置密码 |
| GET/POST | `/api/users/admin/users/` | 管理 | 用户列表/创建 |
| GET/PUT/PATCH/DELETE | `/api/users/admin/users/<id>/` | 管理 | 用户详情/编辑/删除 |

## 7. 前端

- `stores/account.js`：资料读取/更新、改密、重置。
- `views/AccountView.vue`：资料表单 + 改密表单。
- `views/ForgotPasswordView.vue` / `ResetPasswordView.vue`：找回/重置。
- 路由：`/account`（需登录）、`/forgot-password`、`/reset-password`（公开）。
- 顶栏用户头像下拉：账号设置 / 退出。

## 8. 安全与扩展

- 密码校验沿用 `AUTH_PASSWORD_VALIDATORS`。
- 重置令牌一次性、过期、库内只存摘要。
- 邮箱枚举防护：未注册邮箱返回统一文案。
- `DEBUG=True` 时找回密码接口返回 `debug.token`，便于本地无 SMTP 联调。
- 生产 SMTP 配置见 `.env.example` 的「邮件 / 密码重置」段。

